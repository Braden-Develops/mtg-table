Discord bot

Send invite links from Discord: right-click a friend › Apps › Invite to MTG table, pick the table, and the bot DMs them the link. Also /invite, /links, /revoke and /who. Only you can use them.

  1. In the Discord Developer Portal, open your bot's application. Copy the Application ID and Public Key from General Information.
  2. On the Bot page, press Reset Token and copy the new token.
  3. Paste them below and save. The token is kept on the server and never shown again.
  4. Back on General Information, set Interactions Endpoint URL to and save there.
  5. Add the bot to a server (lets it DM people in that server) and to your account (commands work in any DM; turn on User Install on the Installation page first).
  6. Run any command, e.g. /who. The first time, the bot replies with your user ID: paste it below.

Others who can use the bot

    Add people in Discord with /hosts add; only you can.
